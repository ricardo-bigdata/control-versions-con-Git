# control-versions-con-Git
## Obxectivos
- Empregar un sistema de control de versións para rexistra-los cambios no código fonte dunha aplicación. 
- Integrar fluxos de traballo de control de versións no desenvolvemento de aplicacións. 
- Aplicar casos prácticos de desenvolvemento e administración de sistemas mediante a elaboración e mantemento automatizado de documentación con Markdown e Git.

## Contidos
- Creación e manexo de repositorios Git. Traballo en ramas e estratexias de ramificación.
- Colaboración en ferramentas de forxa (GitHub, GitLab) e uso de pipelines para a automatización de procesos de desenvolvemento.
- Fluxos de traballo. Estratexias de ramificación. GitFlow e gitHub Flow.
- Markdown para a elaboración de documentación técnica.
- Boas prácticas no uso de git no ámbito educativo. Casos de usos para sysadmins e para desenvolvedores
